# AutoETL GenAI

## Project title
AutoETL GenAI — Intelligent Data Pipeline Generation and Automated Failure Recovery

## Overview
This project aims to simplify ETL pipeline development using data profiling,
data quality validation, AI-assisted transformation generation, and automated
failure recovery.

## Planned features
- CSV and JSON ingestion
- Schema detection and data profiling
- Data quality validation
- GenAI-assisted transformation generation
- Pipeline execution and failure recovery
- Logging and execution history
- Automated testing

## Technology stack
- Python
- Pandas
- PyYAML
- OpenAI API
- pytest
- Git and GitHub
